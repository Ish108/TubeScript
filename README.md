# TubeScript

A one-page React + Vite YouTube transcript generator with Supabase auth, Supabase history storage, and a Vercel serverless route for Apify.

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Fill `.env`:

   ```bash
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   APIFY_TOKEN=your_apify_api_token
   APIFY_ACTOR_ID=automation-lab/youtube-transcript
   ```

   `VITE_SUPABASE_ANON_KEY` is safe to expose in the browser when Row Level Security is enabled. Never put a Supabase service role key in frontend code.

3. In Supabase SQL Editor, run:

   ```sql
   -- See supabase/schema.sql
   ```

4. Start locally:

   ```bash
   npm run dev
   ```

## Apify actor

The default actor is `automation-lab/youtube-transcript`, chosen because it accepts full YouTube URLs and video IDs, supports auto-generated captions, and can return `fullText` for a clean transcript output.

If you want to use another actor from your Apify Console, set `APIFY_ACTOR_ID` to its slug, for example:

```bash
APIFY_ACTOR_ID=username/actor-name
```

The current API route sends:

```json
{
  "urls": ["https://www.youtube.com/watch?v=VIDEO_ID"],
  "language": "en",
  "includeAutoGenerated": true,
  "mergeSegments": true
}
```

## Deploy to Vercel

1. Import this project into Vercel.
2. Add the same environment variables in Vercel Project Settings.
3. Deploy.

The Apify token stays in the `/api/transcript` serverless function, not in the browser bundle.
